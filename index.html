JavaScript Trivia

A command-line quiz game. Answer against the clock and get instant feedback.

About

This game runs in your terminal, not in the browser. It asks 10 JavaScript questions one at a time, tells you straight away if you were right, and shows your score at the end.

Features

  • Start a game and answer questions one after another
  • Instant feedback: correct, incorrect or time's up
  • 15 seconds per question and 120 seconds for the whole game
  • Final score, points and a list of questions to review
  • Play again without restarting

How to play

  1. Install Node.js (version 18 or newer).
  2. Open a terminal in the project folder.
  3. Start the game:
npm start

Type the letter of your answer (A to D) or its number (1 to 4) and press Enter. Type q to quit.
